# 整改记录 41：双倍额度扩展真实目录更新与服务状态强化

日期：2026-07-12

## 根因

最初把 Bridge 诊断接口返回的 `extension.sourceDir` 当成了 Chrome 当前加载目录。复查内置服务后确认，该字段只是宿主传入的固定扩展源目录，不能证明 Chrome 实际从该目录加载。

## 修改

- 仅把 Chrome 配置中经过校验的解压目录视为真实加载目录，不再混用服务端 `sourceDir`。
- Chrome 真实目录无法识别且仍运行旧版时，明确进入一次性固定目录迁移流程。
- 复制后逐文件执行 SHA-256 一致性校验；校验失败直接报错。
- 页面不再向普通用户显示内部版本号、UTC 时间和管理链路字段。
- 运行控制增加醒目的运行中、启动中、已关闭状态块，并动态更新启动/停止按钮文字。
- Windows 打包忽略测试残留 `.tmp-updates-*` 目录。

## 验证

- 新增现场回归：Chrome 配置扫描为空时，不把服务端 `sourceDir` 错认成 Chrome 实际加载目录。
- 双倍额度服务与桌面渲染专项：67/67 通过。
- 语法检查通过。
- ZIP 内部复核确认包含真实目录接入、逐文件校验、管理链路版本和 `v20260712-preference-verify` 协议。
