## 已交付清单

### 路由与转发稳定性

- 统一 RoutePlan / RouteDecision，普通路由、旧 `cb-*` 模型兜底、Codex 辅助任务、智能切换和 failover 都走同一套决策入口。
- 路由契约矩阵已进入固定检查，覆盖手动路由、旧模型兜底、辅助任务、长上下文、生图路由和失败备用顺序。
- 请求级 smoke 已覆盖真实 `/v1/responses` 链路：旧模型兜底、辅助任务转发、生图代理、上游错误分类和智能失败切换。
- 路由健康状态已区分可用、冷却中、半开恢复、禁用和未验证，避免把 502、超时、流中断误判成长期限流。

### 模型与配置自愈

- RouteSync 已统一接管模型选择、辅助任务模型、智能切换模型、失败备用模型、Router 配置和 Codex 模型缓存。
- 保存供应商、刷新模型、导入配置包、应用配置档、删除自定义模型等入口都会触发 RouteSync。
- 用户改坏或删除 Kimi 等模型后，旧模型引用会被修复，不再长期卡在 `Selected model is not available`。
- Codex 可见模型目录会写入真实 `display_name/name/title`，降低未登录或 API 模式下模型栏显示“自定义”的概率。
- Windows“重启 ChatGPT / Codex”会从桌面、开始菜单、常见安装目录和用户目录推断新版 ChatGPT Desktop 或旧版 Codex Desktop 路径。

### 错误提示与限流

- 401、402、429、5xx、超时、流中断、工具循环等错误已经改为中文短句优先。
- 错误末尾只保留简短“报错信息”，不再把整段 HTML 或大段英文直接甩给用户。
- 只有真实 429 / provider rate limit 才按供应商限流处理；502、503、504、超时和流中断不再被统一说成 CodexBridge 限制。
- 本地限流/保护逻辑支持开关，关闭后不再由 CodexBridge 本地阻断同类请求。

### 上下文与压缩

- 每个模型的 `context_window` 会写入 Codex 可见目录和缓存。
- Chat 路由会按目标上游模型窗口裁剪历史，避免小上下文模型吃到超大上下文。
- 压缩请求会去掉工具并回放摘要为上下文，避免把不完整工具调用链发给 chat 上游。
- 大上下文模型切到小上下文模型的完整真实体验仍需要在 ChatGPT / Codex Desktop 里验收，重点看是否符合用户预期。

### 资源页与能力页

- 资源页插件主统计只使用 Codex CLI 已安装项；MCP 只统计 Codex 设置页可见配置，`node_repl`、插件运行时 MCP、本地缓存、市场候选和未启用项只放高级诊断。
- 插件数量兼容 Codex CLI 只返回 `name/displayName/title` 的格式，避免用户 Codex 显示 5 个插件、CodexBridge 显示 0 个。
- 能力页已收口：图片生成是当前唯一自动接管的扩展能力；OCR、搜索、浏览器、Computer Use、语音、视频等实验能力只用于手动体检和试运行。
- 实验能力未配置时不再作为启动体检或正式发包阻断项。

### 图片生成代理

- 支持多个图片供应商、默认供应商、备用和按模型指定供应商。
- 支持硅基流动、智谱 / Z.ai、OpenAI 和通用接口模板。
- 生成结果会保存本地并在 Codex 里展示；大图不内联 base64，只给本地预览和路径。
- 错误会区分 Key、余额、限流、模型名、尺寸、审核、下载失败和网关错误。

### 自动更新与打包

- 更新逻辑优先 Windows 安装包，便携包只作为便携版或安装包缺失时的备用。
- 下载完成后会校验 EXE / ZIP 文件头，避免把 HTML 错误页当安装包执行。
- 安装版更新会自动打开安装器；便携版更新会用 PowerShell 替换并重启。
- 清理旧包和旧安装目录时遵守项目规则，不使用批量递归删除命令。

### 启动性能与界面收口

- 首屏只请求轻量状态，资源、会话、体检、历史等重数据按页面进入后再加载。
- 旧便携版数据扫描在 Worker 中运行，不再阻塞桌面主线程；运行日志按 5 MB 主文件加 1 个备份轮转。
- 体检、资源、会话、能力页面的长说明已压缩，不再把内部诊断细节默认塞给普通用户。
- 支持诊断报告和路由决策摘要，排查问题时能看到最近请求为什么切换、兜底或失败。

## 给用户看的更新日志

这版主要解决稳定性和可理解性问题：

- 修复模型被改名、删除或同步替换后，Codex 模型栏卡住不可用模型的问题。
- 优化 Kimi、DeepSeek、自定义模型和辅助任务模型的路由稳定性。
- 增强智能失败切换，备用模型不可用时不会乱切。
- 优化供应商错误提示，余额不足、Key 错误、供应商限流、网关异常会用中文说明。
- 增加图片生成代理，非 GPT 模型也可以通过配置的图片供应商完成生图请求。
- 优化 ChatGPT / Codex Desktop 重启路径发现，Windows 会从开始菜单、桌面和常见安装目录查找，优先兼容新版 ChatGPT 并保留旧版 Codex。
- 开始菜单/桌面快捷方式扫描采用共享软预算（最多 24 个候选、128 次目录操作、约 350ms）；单次 Windows 文件系统调用无法强制中断，遇到异常慢的网络桌面或重定向目录时会在该调用返回后停止继续扫描。快捷方式解析另有约 6 秒总预算、单条命令不超过 3 秒；PowerShell、WMIC、tasklist、Store、macOS quit 等辅助命令统一设有 5 秒超时，避免重启操作永久等待。
- 优化资源页和能力页，减少看不懂的诊断信息。
- 优化自动更新流程，安装版优先下载并打开安装器，便携版走便携替换流程。
- 优化启动速度，减少打开软件后首屏卡顿。

## 必须真实验收的项目

这些不是代码本地测试能完全证明的，需要拿测试包在真实机器上跑：

1. Windows 安装版：安装目录选择、桌面图标、关闭旧版、启动新版、安装包清理。
2. Windows 便携版：解压后启动、更新替换、重启、旧包清理。
3. ChatGPT / Codex Desktop 路径发现：开始菜单只有新版 ChatGPT 或只有旧版 Codex 时，对应重启都能成功；ChatGPT Classic 与 CodexBridge 不得被结束。
4. 真实 API Key：Kimi、DeepSeek、OpenAI 或其他供应商至少各跑一次普通对话。
5. 模型自愈：改坏 Kimi 供应商或删除当前模型后，再保存其他供应商，不再报旧模型不可用。
6. 智能失败切换：主模型上游失败时按配置切备用；关闭自动切换时不切。
7. 错误提示：401、402、429、502、超时至少各看一次中文提示是否能被普通用户理解。
8. 图片生成：用真实图片供应商生成图片，确认本地保存、Codex 预览和历史记录可用。
9. 资源页：和当前 Codex 插件/MCP/技能页面数量对齐，缓存项不混进主数量。
10. 大上下文切小上下文：从 1M 模型切到 258K 模型时，确认上下文裁剪或压缩体验可接受。

## 已知边界

- 没有真实 Key 的项目不能算真实供应商验收通过。
- 没有真实安装包目录时，自动更新只能算代码路径通过，不能算端到端安装体验通过。
- 非 GPT 模型不能直接获得 OpenAI 原生 Computer Use、Chrome、ImageGen 能力；当前只有图片生成代理是自动接管能力。
- OCR、搜索、浏览器、Computer Use、语音、视频等实验能力目前只做手动体检和试运行，不会自动改写普通模型路由。
- Markdown 会话导出只用于迁移参考或人工恢复，不会自动写回 ChatGPT / Codex Desktop 本地会话数据库。
- 发布到 GitHub 必须等明确指令；测试包不等于正式 release。


